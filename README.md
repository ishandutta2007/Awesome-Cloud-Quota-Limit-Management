### 📌 Overview & SEO Summary 🔍

Welcome to the definitive, SEO-optimized curated directory of **cloud quota management platforms**, **cloud limit enforcement software**, **multi-cloud resource governance tools**, and **rate limit automation frameworks**. 

As organizations expand across **AWS**, **Microsoft Azure**, **Google Cloud Platform (GCP)**, and **Kubernetes**, managing cloud quotas and resource limits becomes critical to prevent operational outages, avoid sudden billing overages, and maintain compliance. This directory aggregates both hyperscaler native tools (*AWS Service Quotas*, *Azure Resource Quotas*, *Google Cloud Quotas*) and enterprise FinOps/governance platforms (*Broadcom CloudHealth*, *Spot by NetApp*, *Apptio Cloudability*, *Turbot Guardrails*, *Vantage*, *CloudZero*), alongside production-grade open-source limit tools (*Kyverno*, *Karpenter*, *Cloud Custodian*, *Kueue*, *Harbor*, *Sloth*, *QuotaGuard*, *MLBatch*, *Proxmox Cloud Portal*). 📈

## 🔓 Open-Source GitHub Projects 🐙

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Traefik](https://github.com/traefik/traefik)** [![Stars](https://img.shields.io/github/stars/traefik/traefik?style=social&color=white)](https://github.com/traefik/traefik/stargazers)  
  **Modern cloud-native edge router and HTTP reverse proxy with built-in rate limiting and request quota middleware**, open-source. **In-flight request limiting and rate limit policies** protect downstream microservices from traffic spikes. **Dynamic configuration discovery** from Kubernetes, Docker, and Swarm. **Automatic TLS certificate management** via Let's Encrypt. 🚀

- **[Harbor](https://github.com/goharbor/harbor)** [![Stars](https://img.shields.io/github/stars/goharbor/harbor?style=social&color=white)](https://github.com/goharbor/harbor/stargazers)  
  **CNCF Graduated enterprise artifact & container registry with native per-project storage quota limits**, open-source. **Configurable storage quotas** restrict disk usage per project/tenant (e.g., `50GB` storage quota cap). **Automated garbage collection** and image retention policies enforce limit compliance. **Vulnerability scanning & RBAC** for multi-tenant registry security. 📦

- **[Envoy Proxy](https://github.com/envoyproxy/envoy)** [![Stars](https://img.shields.io/github/stars/envoyproxy/envoy?style=social&color=white)](https://github.com/envoyproxy/envoy/stargazers)  
  **Cloud-native high-performance edge and service proxy featuring global gRPC rate limiting & quota enforcement services**, open-source. **Global rate limiting architecture** allows distributed quota tracking using Redis backend. **Circuit breaking & dynamic resource allocation** prevent resource exhaustion across large service meshes. 🌐

- **[Casbin](https://github.com/casbin/casbin)** [![Stars](https://img.shields.io/github/stars/casbin/casbin?style=social&color=white)](https://github.com/casbin/casbin/stargazers)  
  **Powerful and efficient open-source authorization library supporting quota and resource access control policies**, open-source. **ACL, RBAC, ABAC authorization models** across Golang, Java, Python, Node.js, and C++. **Attribute-based quota enforcement** to validate user limits and permissions dynamically. 🔐

- **[ingress-nginx](https://github.com/kubernetes/ingress-nginx)** [![Stars](https://img.shields.io/github/stars/kubernetes/ingress-nginx?style=social&color=white)](https://github.com/kubernetes/ingress-nginx/stargazers)  
  **Official NGINX Ingress Controller for Kubernetes with annotations for connection and request rate limit enforcement**, open-source. **`limit-req-rate` and `limit-connections` annotations** restrict client rate limits per second/minute. **Prevents upstream denial-of-service** and controls ingress bandwidth usage across Kubernetes namespaces. ☸️

- **[Karpenter Provider AWS](https://github.com/aws/karpenter-provider-aws)** [![Stars](https://img.shields.io/github/stars/aws/karpenter-provider-aws?style=social&color=white)](https://github.com/aws/karpenter-provider-aws/stargazers)  
  **High-performance Kubernetes node autoscaler that respects AWS EC2 Service Quotas and instance limits**, open-source. **Dynamic node provisioning** evaluates CloudWatch quota alerts and EC2 vCPU service quotas before scaling. **Optimizes compute cost & availability** by rapidly launching right-sized instances. ⚡

- **[Cloud Custodian](https://github.com/cloud-custodian/cloud-custodian)** [![Stars](https://img.shields.io/github/stars/cloud-custodian/cloud-custodian?style=social&color=white)](https://github.com/cloud-custodian/cloud-custodian/stargazers)  
  **Rules engine for cloud account governance, resource limit auditing, and cost optimization**, open-source. **YAML-based policy enforcement** across AWS, Azure, and GCP. **Detects quota-nearing resources**, unattached volumes, and over-provisioned infrastructure with automated remediation actions. 🛡️

- **[google-cloud-python](https://github.com/googleapis/google-cloud-python)** [![Stars](https://img.shields.io/github/stars/googleapis/google-cloud-python?style=social&color=white)](https://github.com/googleapis/google-cloud-python/stargazers)  
  **Official Google Cloud Python Client Library monorepo containing the Cloud Quotas API client (`google-cloud-cloudquotas`)**, open-source. **Programmatic GCP quota administration** for listing, adjusting, and auditing project quota limits across all GCP services. 🐍

- **[Kyverno Policies](https://github.com/kyverno/policies)** [![Stars](https://img.shields.io/github/stars/kyverno/policies?style=social&color=white)](https://github.com/kyverno/policies/stargazers)  
  **Kubernetes native policy repository featuring schedule-based resource quota enforcement**, open-source. **Time-based ResourceQuota mutation** automatically reduces namespace CPU/memory limits during non-business hours (e.g., 50% quota reduction overnight/weekends) to optimize cloud infrastructure costs. ⏰

- **[Gatekeeper](https://github.com/open-policy-agent/gatekeeper)** [![Stars](https://img.shields.io/github/stars/open-policy-agent/gatekeeper?style=social&color=white)](https://github.com/open-policy-agent/gatekeeper/stargazers)  
  **OPA-based Validating & Mutating Admission Controller for Kubernetes resource limit enforcement**, open-source. **Policy-as-code enforcement** ensures every container specifies CPU/memory request & limit ranges before pod admission. **Prevents noisy-neighbor starvation** and namespace quota breaches. 🚪

- **[Kueue](https://github.com/kubernetes-sigs/kueue)** [![Stars](https://img.shields.io/github/stars/kubernetes-sigs/kueue?style=social&color=white)](https://github.com/kubernetes-sigs/kueue/stargazers)  
  **Kubernetes-native job queueing controller for batch, AI/ML, and HPC resource quota management**, open-source. **ClusterQueue and LocalQueue custom resources** manage resource quota allocation, fair sharing, and queue priorities across multiple tenant teams. 🤖

- **[Sloth](https://github.com/slok/sloth)** [![Stars](https://img.shields.io/github/stars/slok/sloth?style=social&color=white)](https://github.com/slok/sloth/stargazers)  
  **Easy SLO generator for Prometheus with error budget quota monitoring and burn rate alerting**, open-source. **Defines service reliability quotas** and alerts on rapid error budget depletion. **Generates production-grade Prometheus alert rules and Grafana dashboards**. 📉

- **[Karpenter Core](https://github.com/kubernetes-sigs/karpenter)** [![Stars](https://img.shields.io/github/stars/kubernetes-sigs/karpenter?style=social&color=white)](https://github.com/kubernetes-sigs/karpenter/stargazers)  
  **Core Kubernetes node autoscaling framework with built-in resource quota constraints**, open-source. **Just-in-time capacity management** respects cluster-wide resource limits and cloud vendor instance family caps. ☸️

- **[Kyverno Schedule-Based Quotas](https://github.com/kyverno/policies/tree/main/cost-optimization/schedule-based-quotas)** [![Stars](https://img.shields.io/github/stars/kyverno/policies?style=social&color=white)](https://github.com/kyverno/policies/stargazers)

- **[MLBatch (CodeFlare)](https://github.com/project-codeflare/mlbatch)** [![Stars](https://img.shields.io/github/stars/project-codeflare/mlbatch?style=social&color=white)](https://github.com/project-codeflare/mlbatch/stargazers)

## ⚠️ Disclaimer ℹ️

- This is a **community-curated directory** provided for informational purposes — not an endorsement of specific commercial products. ℹ️
- **AWS Service Quotas** is included free with AWS accounts. EC2 vCPU quotas are scoped per-region and per-instance-family. Standard increase requests take 1–3 business days. ☁️
- **Azure Quotas** does not natively cover Cosmos DB limit queries (requires Azure Resource Graph). StandardCore VM increases may require direct support request contact. 🔷
- **Google Cloud Quotas** requires enabling both `cloudquotas.googleapis.com` and target service APIs with appropriate IAM permissions (`roles/cloudquotas.viewer` or `roles/cloudquotas.admin`). 🌐
- **Open-source quota management tools** (e.g., QuotaGuard, Kyverno, Kueue, Cloud Custodian) require proper configuration and testing in non-production environments before enterprise deployment. 🛡️
